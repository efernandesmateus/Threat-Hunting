# Decisões (ADRs)

Registro das decisões de design do projeto. Cada decisão explica o contexto, o que foi decidido e as consequências, para que qualquer pessoa entenda por que a metodologia é como é.

## Como registrar uma decisão

1. Copie a estrutura de um ADR existente.
2. Nomeie como `NNNN-titulo-curto.md`, com numeração sequencial.
3. Status possíveis: **Proposta**, **Aceita**, **Substituída por NNNN**, **Descontinuada**.
4. Uma decisão aceita não é editada; se mudar, crie um novo ADR que a substitua.
