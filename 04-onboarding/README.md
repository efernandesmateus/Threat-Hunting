# 04 — Onboarding de cliente

Prepara o cliente para receber o serviço. Sem saber quais dados existem e com que qualidade, não é possível testar hipóteses.

## Conteúdo previsto

- Checklist de onboarding (contatos, escopo, acessos, janela de execução, regras de escalonamento).
- Inventário de fontes de dados: o que é coletado, com que retenção e cobertura.
- Matriz de cobertura: quais hunts da biblioteca são viáveis para o cliente, de acordo com as fontes disponíveis.
- Critérios de qualidade de dados (disponibilidade, completude, consistência, atualidade).
