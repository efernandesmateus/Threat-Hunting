# 04 — Onboarding de cliente

Prepara o cliente para receber o serviço. Sem saber quais dados existem e com que qualidade, não é possível testar hipóteses.

## Documentos

| Documento | Uso |
|-----------|-----|
| [Checklist de onboarding](checklist-onboarding.md) | Roteiro em seis fases, do kick-off ao aceite, com responsáveis e regras de acesso |
| [Template da ficha do cliente](template-ficha-cliente.md) | Registro dos acordos: contatos, escalonamento, modo de resposta, ações pré-autorizadas, acessos |
| [Template do inventário de fontes](template-inventario-fontes.md) | Fontes de dados do cliente, retenção, cobertura e qualidade em quatro critérios |
| [Matriz de cobertura](matriz-de-cobertura.md) | Método para definir quais hunts são viáveis e quais fontes priorizar, com mapa de referência das fontes por hunt |

Os templates são **modelos**: as versões preenchidas descrevem o ambiente do cliente e ficam fora deste repositório ([ADR 0003](../decisoes/0003-sem-dados-reais-no-repositorio.md)).

## Valores de referência

A duração de até 30 dias, a revisão trimestral dos acessos e as demais frequências citadas são **referências ajustáveis** por contrato.
